# Sonic Animation Viewer PRD

## 1. 문서 목적

`pre-prd.md`에 적힌 요구사항을 구현과 검증이 가능한 개발 기준으로 구체화한다. 이 문서에 적히지 않은 기능이나 수치는 확정 요구사항으로 간주하지 않는다.

## 2. 제품 개요

Sonic 스프라이트 시트에 포함된 애니메이션을 차례대로 재생해 확인하는 Python 프로그램이다. 각 애니메이션을 5회 반복하고 1초 쉬었다가 다음 애니메이션으로 넘어가며, 전체 재생이 끝나면 처음부터 계속 반복한다.

## 3. 목표와 범위

### 목표

- 스프라이트 시트에 포함된 모든 애니메이션을 빠짐없이 재생한다.
- 애니메이션별 반복 횟수와 전환 대기 시간을 일관되게 적용한다.
- 스프라이트를 화면에서 잘 알아볼 수 있는 크기로 확대해 보여준다.
- 구현 과정을 작은 단계로 나누고, 의미 있는 변경을 최소 20회 커밋으로 기록한다.

### 범위에 포함

- Python과 `pico2d`를 사용한 애니메이션 뷰어
- 단일 Python 파일 `sonic_animation.py`
- 스프라이트 이미지 `sonic-sprite.png`
- 스프라이트 시트에 있는 애니메이션의 순차 재생과 무한 반복

### 범위에 포함하지 않음

- 사용자 입력으로 애니메이션을 선택하거나 재생을 제어하는 기능
- 사운드, 점수, 게임 규칙 등 애니메이션 재생 이외의 기능
- 여러 Python 모듈로 나누는 구조

## 4. 실행 환경과 산출물

| 항목              | 요구사항                         |
| ----------------- | -------------------------------- |
| 언어              | Python                           |
| 그래픽 라이브러리 | `pico2d`                       |
| 프로그램 파일     | `sonic_animation.py` 단일 파일 |
| 이미지 파일       | `sonic-sprite.png`             |
| 창 크기           | 1200 × 800 픽셀                |

실행 시 지정된 스프라이트 이미지와 `pico2d`를 사용해야 한다. 스크립트와 이미지의 실행 위치 관계는 구현 전에 확인하고, 실행 방법에 명시한다.

## 5. 기능 요구사항

### FR-01: 스프라이트 이미지 로드

프로그램은 `sonic-sprite.png`를 읽어 애니메이션 프레임을 표시해야 한다. 이미지 로드에 실패하면 원인을 확인할 수 있도록 오류를 알려야 한다.

### FR-02: 스프라이트 시트 프레임 표시

스프라이트 시트에서 각 애니메이션의 프레임 영역을 구분해 표시해야 한다. 프레임의 좌표와 크기는 실제 이미지 파일을 확인해 정하며, 확인하지 않은 좌표를 추측해 사용하지 않는다.

### FR-03: 모든 애니메이션 재생

스프라이트 시트에 담긴 모든 애니메이션을 정해진 순서로 재생해야 한다. 애니메이션 목록과 순서는 시트의 실제 구성을 확인한 뒤 코드에 명시한다.

### FR-04: 애니메이션별 5회 반복

현재 애니메이션의 전체 프레임 재생을 1회로 세고, 같은 애니메이션을 총 5회 재생한 뒤 다음 애니메이션으로 넘어가야 한다.

### FR-05: 동작 사이 1초 대기

애니메이션 하나의 5회 재생이 끝나면 1초 동안 기다린 뒤 다음 애니메이션 재생을 시작해야 한다. 마지막 애니메이션 뒤에도 같은 대기를 적용한 후 첫 애니메이션으로 돌아간다.

### FR-06: 전체 애니메이션 무한 반복

마지막 애니메이션 재생이 끝나면 프로그램을 종료하지 않고 첫 애니메이션부터 전체 순서를 다시 재생해야 한다.

### FR-07: 화면 표시 크기 확대

스프라이트 프레임을 원본보다 확대해 표시해야 한다. 확대 배율은 초안에 지정되어 있지 않으므로 실제 실행 화면에서 캐릭터가 잘 보이고 프레임이 잘리지 않는 크기를 확인해 결정한다.

### FR-08: 창 크기

프로그램 창은 가로 1200픽셀, 세로 800픽셀로 생성해야 한다.

## 6. 재생 규칙

1. 스프라이트 이미지와 애니메이션 프레임 정보를 준비한다.
2. 현재 애니메이션의 프레임을 순서대로 표시한다.
3. 현재 애니메이션을 총 5회 재생한다.
4. 1초 기다린 뒤 다음 애니메이션으로 이동한다.
5. 마지막 애니메이션 뒤 1초 기다리고 첫 애니메이션부터 반복한다.

프레임 재생 속도와 프레임 좌표는 `pre-prd.md`에 지정되어 있지 않다. 스프라이트 시트와 실행 결과를 확인한 뒤 구현 중 결정하고, 결정한 값을 코드와 검증 기록에서 확인할 수 있게 한다.

## 7. 완료 기준

- [ ] Python 프로그램이 `pico2d`를 사용해 실행된다.
- [ ] 프로그램이 `sonic-sprite.png`를 읽는다.
- [ ] 스프라이트 시트에 포함된 모든 애니메이션이 빠짐없이 재생된다.
- [ ] 애니메이션 하나가 정확히 5회 재생된 후 다음으로 넘어간다.
- [ ] 애니메이션 전환 사이에 1초 대기가 적용된다.
- [ ] 마지막 애니메이션 다음에 첫 애니메이션으로 돌아가 무한 반복한다.
- [ ] 프로그램 창 크기가 1200 × 800 픽셀이다.
- [ ] 캐릭터가 화면에서 알아보기 쉬운 크기로 표시되고 프레임이 잘리지 않는다.
- [ ] 구현 코드는 `sonic_animation.py` 한 파일에 들어 있다.
- [ ] 의미 있는 개발 변경과 검증 결과가 최소 20회의 커밋으로 기록되어 있다.
- [ ] 모든 커밋 메시지는 한글로 작성되어 있다.

## 8. 검증 계획

- 이미지 파일 경로와 `pico2d` 설치 여부를 확인하고 프로그램을 실행한다.
- 화면에 표시되는 프레임을 스프라이트 시트와 대조해 프레임 영역이 맞는지 확인한다.
- 애니메이션 목록을 하나씩 대조해 누락이나 잘못된 순서가 없는지 확인한다.
- 각 애니메이션이 5회 재생되는지 관찰한다.
- 한 애니메이션의 마지막 재생과 다음 애니메이션 시작 사이의 대기가 1초인지 확인한다.
- 마지막 애니메이션이 끝난 뒤 첫 애니메이션부터 다시 재생되는지 확인한다.
- 실행 창의 크기가 1200 × 800 픽셀인지 확인한다.
- 확대된 프레임이 화면에서 잘 보이고 잘리지 않는지 확인한다.
- `git log`와 변경 내용을 확인해 최소 20회의 커밋이 각각 실제 구현 또는 검증 변경을 기록하는지 확인한다.
- `git log --format=%s`로 커밋 제목을 확인해 모든 커밋 메시지가 한글로 작성되었는지 확인한다.

## 9. 단계별 개발 및 커밋 계획

커밋할 때 메시지는 반드시 한글로 작성한다. 각 단계의 커밋 제목은 해당 변경 내용을 한글로 표현한다.

한 번에 전체 코드를 작성하지 않는다. 각 단계는 실행 또는 코드 검토로 확인한 뒤, 해당 단계의 실제 변경을 커밋한다. 커밋 수를 채우기 위한 빈 커밋이나 의미 없는 변경은 만들지 않는다.

1. `pico2d` 실행 환경과 이미지 파일 경로 확인
2. 단일 스크립트 실행 진입점 구성
3. 기본 창 생성 및 종료 처리
4. 스프라이트 이미지 로드
5. 이미지 로드 오류 처리 확인
6. 스프라이트 시트 크기와 프레임 배치 조사
7. 애니메이션 목록과 프레임 데이터 정의
8. 프레임 영역 경계 검토
9. 단일 프레임 출력
10. 확대 출력 크기와 화면 내 위치 조정
11. 한 애니메이션의 프레임 순차 재생
12. 프레임 전환 속도 조정 및 확인
13. 애니메이션 1회 재생 단위 구현
14. 애니메이션별 5회 반복 구현
15. 반복 횟수 경계 확인
16. 애니메이션 사이 1초 대기 구현
17. 다음 애니메이션으로 순서 전환
18. 마지막 애니메이션에서 첫 애니메이션으로 순환
19. 전체 애니메이션 목록과 누락 여부 검증
20. 확대 화면에서 잘림과 가시성 검증
21. 장시간 무한 반복 실행 검증
22. 실행 방법과 확인 결과 문서화 및 최종 점검

위 계획은 최소 20개의 검증 가능한 개발 단계로 구성한다. 실제 작업에서는 한 단계가 독립적인 변경과 확인으로 성립할 때 커밋하며, 불필요하게 단계를 나누거나 합치지 않는다. 최종 커밋 수는 20회 이상이어야 한다.

## 10. 초안에서 미정인 항목

다음 항목은 초안에 구체적인 값이 없으므로 구현 전 실제 자료와 실행 결과를 바탕으로 결정한다.

- 스프라이트 시트의 애니메이션 이름, 프레임 좌표, 프레임 수 및 재생 순서
- 프레임 재생 속도
- 구체적인 확대 배율
- Python과 `pico2d`의 설치 및 실행 명령
